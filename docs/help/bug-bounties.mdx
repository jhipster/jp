# <i class="fa fa-usd"></i> バグ報奨金

## はじめに

[JHipsterバグ追跡システム](https://github.com/jhipster/generator-jhipster/issues)で開かれたチケットには、"\$\$ bug-bounty \$\$"というラベルを付けることができます。チケットを解決した人には、チケットに応じて100ドル、200ドル、300ドル、500ドルのいずれかの金額が与えられます。

## バグ報奨金は誰が作れますか?

- [シルバー、ゴールド、プラチナスポンサー](/sponsors/)
- [プロジェクトリーダー](/team/#project-leads)と[運営委員会](/team/#governing-body)

## バグ報奨金はいくらですか?

"\$\$ bug-bounty \$\$"ラベルの隣には、"$100"、"$200"、"$300"、または"$500"ラベルが表示され、バグ報奨金の価値が示されます。

## 現在オープンされているバグ報奨金のリストはどこにありますか?

バグ報奨金は、主にメインプロジェクトで利用できますが、GitHubのJHipster組織のサブプロジェクトで開くこともできます。

- [すべてのプロジェクトのオープンなバグ報奨金](https://github.com/search?l=&p=1&q=is%3Aissue+is%3Aopen+label%3A%22%24%24+bug-bounty+%24%24%22+user%3Ajhipster+state%3Aopen&ref=advsearch&type=Issues&utf8=%E2%9C%93)
- [メインプロジェクトのオープンなバグ報奨金](https://github.com/jhipster/generator-jhipster/labels/%24%24%20bug-bounty%20%24%24)
- [JHipster VueJSサブプロジェクトのオープンなバグ報奨金](https://github.com/jhipster/jhipster-vuejs/labels/%24%24%20bug-bounty%20%24%24)

## バグバウンティの作成方法

バグ報奨金が作られれば、誰でも修正を提案できます（[プロジェクトリーダー](/team/#project-leads)や[運営委員会](/team/#governing-body)でさえも!）。私たちの目標は、そのお金を使って、何かができるだけ早く修正されるようにすることです。

- シルバー、ゴールド、またはプラチナスポンサーが、バグバウンティラベルの追加を依頼するコメントを追加し、GitHubで[プロジェクトリーダー](/team/)のいずれかにメンションする。
- [プロジェクトリーダー](/team/)と[運営委員会](/team/)は、それが重要な新機能、重大なバグ、長年の課題、または時間のかかるタスクであると判断した場合、直接バグバウンティラベルを追加します。もしあなたが課題に取り組んでいて、それがバウンティに値すると考えるなら、遠慮なくプロジェクトリーダーの一人に尋ねてください。

バグバウンティが有効であるためには、[\$\$ bug-bounty \$\$](https://github.com/jhipster/generator-jhipster/labels/%24%24%20bug-bounty%20%24%24)ラベルが
[プロジェクトリーダー](/team/)または[統治機関](/team/)によって追加されている必要があります。また、その価値を示すために「$100」、「$200」、「$300」、または「$500」のラベルが付いている必要がありますが、そのタグが忘れられている場合は、デフォルトで「$100」の価値があります。


## 誰がバグバウンティを請求できますか？

バグバウンティは、問題を修正した人に支払われます。それは、それに取り組むことを選択し、変更を説明でき、
レビューでその責任を負う人です。AIアシスタントをツールとして使用することは問題ありません。その作業はあなたのものであり、あなたが責任を負います。

自動化されたアカウントは対象外です。ボットまたは自律的に動作するエージェントによって開かれたプルリクエストは、バグバウンティを獲得することはなく、
彼らに代わって問題を主張するコメントも同様です。


## 報酬の受け取り方

バグバウンティが作成されたら、誰でも修正を提案できます（[プロジェクトリーダー](/team/)や[統治機関](/team/)でさえも！）。私たちの目標は、そのお金を使って、できるだけ早く何かを修正することです。

報酬を請求するには、次のことを行う必要があります。

- 「\$\$ bug-bounty \$\$」ラベルが付いたチケットを修正するプルリクエストを作成します。
- チケットを自動的にクローズするには、`Fix`キーワードを含むコミットメッセージが1つ必要です。例えば、チケット`#1234`をクローズするには`Fix #1234`とします。
- そのプルリクエストは、コアチームのメンバーによってマージされる必要があります。複数のプルリクエストがある場合、コアチームのメンバーは最新のものか最良のもののいずれかを選択します。プロジェクトにとって何が最善であるかは、そのチームメンバーが決定します。
- その後、コアチームのメンバーがそのプルリクエスト上で、それがバグバウンティの対象であることを確認する必要があります。これは、作業が自動化されたアカウントからではなく、人から来ていることを確認する方法です。このコメントがないと、費用は承認されません。
- その後、[JHipster OpenCollectiveに$100、$200、$300、または$500の費用を追加](https://opencollective.com/generator-jhipster/expenses/new)できます。説明にはプルリクエストへのリンクを追加する必要があります（例：`$100 bug bounty claim for https://github.com/jhipster/generator-jhipster/pull/1234`）。
- 次に、報酬を請求したことを示すコメントをプルリクエストに追加し、OpenCollectiveの費用へのリンクを記載する必要があります。これは、問題を修正した人と報酬を請求した人が同一人物であることを確認するためです。
- その費用は、プルリクエストの確認をチェックする[プロジェクトリーダー](/team/)または[統治機関](/team/)によって承認され、あなたのPaypalアカウントに報酬が支払われます。
